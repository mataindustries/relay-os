# Domain boundary

Framework-free RelayOS business rules live here. Phase 2 extends the completed one-company/one-role
aggregate with immutable plain-text source versions, exact line anchors, explicit-topic coverage,
reconciled gaps, deterministic interview records, and immutable answer provenance. The Phase 1
claim lifecycle, append-only decisions, repository contract, and employee selector remain the
publication boundary. React, browser APIs, storage adapters, and demo fixtures stay outside.
