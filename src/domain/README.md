# Domain boundary

Framework-free RelayOS business rules live here. Phase 3 extends the completed one-company/one-role
aggregate and Phase 2 evidence/interview engine with structured employee questions, deterministic
eligibility gates, immutable answers, escalations, genuine gap links, and append-only activity
events. The Phase 1 claim lifecycle, decisions, repository contract, and employee selector remain
the publication boundary. React, browser APIs, storage adapters, and demo fixtures stay outside.
