# Demo boundary

Phase 3 extends the fixed, clearly fictional Summit Comfort Heating & Air
record. Its identifiers, timestamps, evidence, topic claims, structured employee
questions, gate traces, answers, escalations, gaps, activity events, and decisions
are deterministic. Loading the fixture repeatedly is idempotent.

Demo code must use the same domain and repository boundaries as user-entered
data. It must not call a model, use browser persistence, make network requests,
or bypass approval and employee-visibility rules.
