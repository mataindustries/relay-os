# RelayOS pilot delivery checklist

This document is the durable human-owned checklist. The matching `/pilot/delivery` page is interactive only for the current component session and does not persist completion.

## Scope and source review

- [ ] Company and one Home-Service Office Manager / Dispatcher role are verified.
- [ ] Sources are organized and obsolete/conflicting versions are identified.
- [ ] Critical topics are reviewed.
- [ ] Source references for employee-visible claims resolve.
- [ ] Approval decisions exist for the exact current claim versions.

## Authority, escalation, and employee guidance

- [ ] Authority map is approved.
- [ ] Numeric limits and currencies are represented structurally where applicable.
- [ ] Escalation map is approved with explicit destinations and required context.
- [ ] Employee guidance is reviewed through the approved-only selector.
- [ ] Proposed, rejected, conflicting, missing, and superseded claims are absent from guidance.

## Demonstration and gap review

- [ ] Within-limit discount scenario is tested.
- [ ] Above-limit discount escalation is tested.
- [ ] Technician-late handling guidance is tested.
- [ ] Over-authority customer commitment escalation is tested.
- [ ] Gaps are documented, and known escalation outcomes have not created fake gaps.

## Delivery package

- [ ] Role Transfer Report is generated from actual current records.
- [ ] Operating Manual summary is generated and contains no invented procedure steps.
- [ ] Report and manual print layouts are checked before PDF delivery.
- [ ] Default-minimized JSON handoff is downloaded.
- [ ] Any source-text inclusion received explicit owner confirmation.
- [ ] Client is told that Phase 4 provides no import or durable persistence.

## Walkthrough and follow-up

- [ ] Employee walkthrough is completed.
- [ ] Owner walkthrough is completed.
- [ ] Session-only, no-authentication, and public-data restrictions are explained.
- [ ] Deliverables are moved through the agreed controlled private channel.
- [ ] Next review date is recorded outside RelayOS.
- [ ] Case-study permission is requested separately, with no fabricated quote or result.
